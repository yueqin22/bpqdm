# mock_comm.c -- 本用例私有, 提供三类东西, 都**不按侧重命名**:

#       PieVectTable / IER) 加 EALLOW-EDIS 计数表 gHostCpuCtl[]。它们是模块的

#       GetNumberDigit1 的逐字副本。

# 不链 hostlib_mock.c: 活代码不调用 qsqrt / qsin / qatan 这些定点数学。

#   位域布局就是被测对象的一部分), hw_mock 那种寄存器文件替身会把布局差异抹平。
