# f_io 用例要链接的 mock 清单 (相对 tools/difftest/)。
#
# mock_io.c -- 本用例私有, 提供三类东西, 都**不按侧重命名**:
#   (1) 六个外设对象 (ECap1Regs / EPwm4Regs / EPwm5Regs / EPwm6Regs /
#       GpioCtrlRegs / GpioDataRegs) 加 CPU 控制计数表 gHostCpuCtl[]。
#       它们是模块的输入兼输出面, 两侧必须绑到同一份。
#   (2) 模块读的工程全局量 (funcCode / runFlag / errorCode / dspStatus / frq /
#       motorFc / aoComm / doComm / curTime ...), 由 driver 每例供值。
#   (3) 三个被调函数的替身: TorqueLimitCalc (可参数化) 与
#       FcDigit2Bin / GetNumberDigit (逐字副本)。
#
# 不链 hostlib_mock.c: 活代码不调用 qsqrt / qsin / qatan 这些定点数学。
# 不链 hw_mock.c: 本模块要的是**真**寄存器模型 (ECAP_REGS / EPWM_REGS /
#   GPIO_CTRL_REGS 的位域布局就是被测对象的一部分), hw_mock 那种寄存器文件替身
#   会把布局差异抹平。
# 不链 hw_mock_p2p.c: 本模块不碰 p2pData。
